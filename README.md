# 宋瓷五窑纪 · 作品说明文档

## 二、创意理念

宋代五大名窑是中国陶瓷史的巅峰，但对大众尤其是青少年而言，"汝官哥钧定"只是五个抽象名词。本作品以**"穿越北宋当窑主"**为叙事主线，把知识科普变成一场角色扮演旅程：

> 玩家接手一座瓷窑，巡五窑、学工艺、亲手烧瓷，集齐五窑印章成为"大宋窑主"。

首页的穿越引子、每页的窑口剧情语、全站集印进度条共同构成完整叙事，让"看展"变成"入戏"。

## 三、核心交互模块（互动体验）

### 1. 窑变盲盒（kilnbox.html）——主打招牌
"入窑一色，出窑万彩"是钧窑天然的游戏机制。玩家选坯型→入窑升温（1280℃ 动画）→开窑瞬间生成**随机窑变釉**（Canvas 程序化渲染：天蓝釉底 + 铜红斑彩 multiply 叠加 + 釉下气泡 + 玉质高光）→ 评级（常品/上品/珍品）→ 可存入收藏或**一键生成分享卡片下载**。
- 科普原理：钧釉以铜为着色剂，高温还原焰中铜离子价态变化 + 釉层流动形成窑变，古代不可控，故每件钧瓷独一无二。

### 2. 开片实验室（crackle.html）——技术亮点
玩家调节**胎釉膨胀差、釉层厚度、冷却速度**三个参数，点击"开窑冷却"后，Canvas 实时生长出冰裂纹 / 鱼子纹 / 蟹爪纹 / 大开片等不同开片形态。
- 算法：随机种子点 + 角度随机游走的分支裂纹逐帧生长。
- 科普原理：胎与釉膨胀系数不同，冷却时釉面受拉开裂；哥窑匠人再以墨汁、茶汁染出"金丝铁线"，变缺陷为美学。

### 3. 窑主试炼（funfact.html）——集印主线
五窑知识闯关，每窑 3 题（素材取自本站档案与冷知识），全对即授予该窑**印章**（盖章动画），全站导航栏实时显示"印 n/5"进度，首页有集印墙。印章存于 localStorage，跨页面持久。

### 4. 瓷韵 DIY（workshop.html 原有模块）
拉坯塑形→釉色调配→纹饰装饰→入窑烧制的完整制瓷流程模拟。

### 5. 3D 点云瓷瓶（五窑详情页）
每窑 8.3 万点真 3D 扫描点云，可拖拽 360° 旋转、滚轮缩放，数据由 .obj + PBR 贴图离线提取（extract_obj.py）。

## 四、技术要点

- **零依赖纯前端**：原生 HTML/CSS/JS，无框架，可直接部署到任意静态托管（GitHub Pages / Netlify / 校内服务器）。
- **程序化釉色渲染**：Canvas 径向渐变 multiply 混合模拟窑变，裂纹随机生长算法模拟开片，无需任何图片素材即可无限生成。
- **中英双语体系**：自研 i18n 字典 + localStorage 语言记忆，全站一键切换。
- **性能**：DPR 自适应、移动端粒子降载、点云按窑拆分（可选优化项）。
- **健壮性**：全局错误捕获弹窗、网络超时处理、后台标签页动画不冻结（setTimeout 步进降级）。

## 五、应用场景

1. **博物馆 / 非遗馆青少年科普互动屏**：三大交互即开即玩，无需安装。
2. **中小学美育 / 劳育课堂**：开片实验室与窑变盲盒可作为"材料科学 + 美学"跨学科课件。
3. **文旅传播**：分享卡片自带传播属性，适合新媒体二次扩散。
4. **海外文化传播**：双语界面，服务"中国故事"国际表达。

## 六、运行方式

静态站点，无需构建。任意静态服务器指向本目录即可：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

演示动线建议：首页（穿越引子）→ 汝窑页（3D 点云 + 开片实验室入口）→ 钧窑页（窑变盲盒）→ 窑主试炼（集印收尾）→ 我的收藏（展示成果）。

## 七、素材与工具说明

- 瓷器图像：博物馆公开藏品图及 AI 生成海报图，仅用于非营利科普展示。
- 3D 点云：由公开 .obj 模型 + PBR 贴图经自研脚本（extract_obj.py / extract_points.py）离线提取。
- AI 工具使用说明：海报底图等视觉素材使用了生成式 AI 辅助绘制，经人工筛选与后期处理；全部交互逻辑、渲染算法、文案内容为团队原创编写。
